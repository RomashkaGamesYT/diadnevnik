# 🩺 DIABLOG — Дневник диабетика

**DIABLOG** — это современное, адаптивное и интуитивно понятное веб-приложение (HTML/CSS/JS) для ежедневного контроля сахарного диабета. Проект создан для того, чтобы избавить пользователя от бумажной рутины и предоставить наглядную аналитику его состояния прямо в браузере.

---

## ✨ Ключевые особенности (Features)

*   **📊 Новое: Интерактивный график сахара!** Визуализируйте тренды, отслеживайте динамику глюкозы в течение дня и находите закономерности после приемов пищи.
*   **📈 Карточки быстрой статистики:** Главный экран сразу показывает ключевые метрики за день — «Средний сахар» и «Съедено ХЕ» (хлебных единиц) по отношению к суточной норме.
*   **➕ Мгновенное добавление записей:** Быстрая кнопка для фиксации новых замеров, инъекций и приемов пищи.
*   **📱 Мобильный интерфейс:** Удобное нижнее навигационное меню (Таббар) для быстрого переключения между экранами:
    *   `Главная` — дашборд со сводкой и важными обновлениями.
    *   `Дневник` — подробная история всех записей и логов.
    *   `График` — выделенный экран глубокой аналитики.
    *   `Профиль` — личные настройки, целевые диапазоны и нормы ХЕ.
*   **🔒 Локальность и приватность:** Приложение работает на базе `localStorage` / `IndexedDB`. Данные хранятся только на устройстве пользователя и не отправляются на сторонние серверы.

---

## 🛠️ Технологический стек (Tech Stack)

*   **HTML5** — семантическая структура интерфейса.
*   **CSS3** — современная верстка, кастомные CSS-переменные для стильной зеленой палитры и плавная анимация переключения табов.
*   **Vanilla JavaScript (ES6+)** — архитектура без тяжелых фреймворков, логика расчета средних показателей и обработка кликов.
*   *(Опционально)* **Chart.js** — для построения графиков динамики глюкозы.

## 📦 Быстрый старт (Installation)

Проект является pure-фронтенд приложением, серверная часть не требуется.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   ```
2. **Запустите проект:**
   Просто откройте файл `index.html` в любом современном браузере (Chrome, Safari, Firefox, Edge).

```text
├── index.html          # Главная страница (Дашборд, Дневник, Графики, Профиль)
```
